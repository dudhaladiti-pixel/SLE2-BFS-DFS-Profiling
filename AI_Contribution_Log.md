# AI Contribution Log

## SLE-2: Empirical Performance Analysis

---

## 1. AI Tool Used

**AI Tool:** ChatGPT

AI assistance was used during the development and documentation of this SLE-2 project.

---

## 2. Purpose of AI Assistance

ChatGPT was used to:

* Understand the SLE-2 assignment guidelines.
* Understand the concept of profiling and empirical performance analysis.
* Select BFS and DFS as the two algorithms for comparison.
* Understand how BFS and DFS work on a small graph.
* Get guidance for preparing Python code.
* Understand how to install and use py-spy.
* Get guidance on generating py-spy profiling output and flame graphs.

---

## 3. AI-Assisted Code

AI assistance was used to help prepare the initial structure of the BFS and DFS Python programs.

The code was then reviewed and tested by the student.

The main files involved are:

* `bfs.py`
* `dfs.py`
* `bfs_profile.py`
* `dfs_profile.py`

---

## 4. Profiling and Experimentation

The actual experiment was performed by the student.

The student:

* Run the BFS program.
* Run the DFS program.
* Used the same graph for both algorithms.
* Installed and used py-spy.
* Generated BFS and DFS profiling results.
* Observed the generated flame graphs.
* Recorded the number of nodes expanded.
* Compared the experimental results.
* Prepared the final analysis based on the obtained results.

The student was responsible for:

## 6. Transparency Statement

AI was used as a learning and development assistant. The experimental results were not generated by AI. The results reported in the SLE-2 report were obtained by running the programs and performing the profiling experiment.

The final analysis was based on the student's actual experimental observations and results.
